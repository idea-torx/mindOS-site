Security

Source: SECURITY.md in the runtime repository · All docs

What MindOS will never do (v1 contract)

MindOS is a registry and evidence layer. It does not: deploy, merge, or push code; send external messages or call external APIs for writes; submit applications or take side effects on any external system; run arbitrary agent commands; or access Keychain values or credential stores.

Data boundary

All state lives in a local SQLite home ($MINDOS_HOME). The repository itself must never contain live databases, receipts, installation reports, session archives, Hindsight exports, backups, runtime artifacts, .env files, or Claude memory contents.

Secret guard

Every user-supplied text field passes shape detectors that block, redact, or — only under an explicit, audited override — allow credential-shaped values, so fleet sweeps can still locate them. Legacy rows sitting in live notes/handoffs are reported with the same detectors.

Tamper-evident audit

A global hash-chained event stream records every transition; verify-chain recomputes the chain and reports tampering. Audit events are digest-only where values could be sensitive.
