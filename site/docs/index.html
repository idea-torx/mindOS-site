Documentation

Everything here is grounded in the runtime repository’s README, ARCHITECTURE, INSTALL, SECURITY, ROADMAP, CHANGELOG, and STABILITY docs. Each page links back to its source.

MindOS is the durable local operating system for Hermes and cooperating AI agents. It combines SQLite-backed execution truth, a Hindsight shared semantic memory binding, temporal facts, task ownership with live leases, sealed receipts, provenance, session archives, profiles, skills, cron definitions, migration, recovery, and rollback — behind one CLI surface with no server to deploy.
