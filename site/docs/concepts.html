Concepts

Source: README.md in the runtime repository · All docs

Tasks and ownership

A task is the unit of work: project, title, priority, status, next action, dependency edges, and an audited history. Work is claimed, not assigned — an agent acquires a live lease with a monotonic fencing epoch.

Leases and fencing epochs

Every lease acquisition bumps lease_epoch. A holder passes its epoch back on mutations so a stale process is rejected even when the owner name still matches. Heartbeats keep leases alive; renew extends without changing status; release hands a task back without consuming retry budget.

Sealed receipts

Evidence files written 0600 with a sha256 recorded in the audit trail. Completions require one — "tests pass" in chat is not proof.

Temporal facts

A provenance-linked graph of evolving triples with validity windows: fact-assert, facts, search-facts with BM25 retrieval and temporal hybrid rerank.

Handoffs

Cross-agent handoffs embed a full recall bundle (task header, dependencies, live handoff, receipts, notes) with recall digests, so the receiving agent resumes with evidence rather than a chat summary.

Seam conflicts

Leases prevent two agents taking the same task; seams prevent two agents editing the same checkout — an identical non-empty worktree path or the same branch in the same project is refused at claim time.
