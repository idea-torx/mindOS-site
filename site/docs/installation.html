MindOS — Autopilot v2

Installation

Source: INSTALL.md in the runtime repository · All docs

Prerequisites

  • Python 3.9+ (standard library only; no third-party packages)
  • macOS or Linux

Install

git clone <repo-url> mindos
cd mindos
export MINDOS_HOME="$HOME/.hermes/mindos"
python3 autopilot.py init
python3 ops.py doctor

Health checks

ops.py doctor verifies schema, lease state, audit chain, and FTS5 inverted-index health — including drift detection via fts5vocab. It is safe to run from monitoring cron before committing to a real pass.

Upgrading

Migration between homes is dry-run-first, journaled, and one-command reversible — see Migration. The end-to-end suite (verify.py) exercises interrupted re-runs and rollback to zero before any release.
