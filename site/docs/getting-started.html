MindOS — Autopilot v2

Getting started

Source: INSTALL.md in the runtime repository · All docs

MindOS is a local control plane — there is no server to deploy and no third-party packages. Python 3.9+ on macOS or Linux is the only prerequisite.

git clone <repo-url> mindos
cd mindos
export MINDOS_HOME="$HOME/.hermes/mindos"   # any writable path works
python3 autopilot.py init
python3 ops.py doctor                        # health-check the new home

init creates the SQLite schema (state.db, plus temporal.db when the fact graph is used). All commands accept the home via MINDOS_HOME / HERMES_AUTOPILOT_HOME.

Your first task

python3 autopilot.py create --project Trove --title "Ship render fix" --priority P1
python3 autopilot.py claim tsk_4f2a --owner hermes --minutes 30
python3 autopilot.py heartbeat tsk_4f2a --owner hermes --note "Running verification"
python3 autopilot.py receipt tsk_4f2a --kind verification --payload '{"tests":"pass"}'
python3 autopilot.py complete tsk_4f2a --owner hermes --note "tests pass"

Completions require a live lease and a sealed receipt — claims without evidence are rejected by policy, not by convention.

Seeding an initial queue (optional)

seed_current_state.py demonstrates upserting a task queue without executing any work. Point it at your own home and edit the item list first.
