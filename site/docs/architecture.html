Architecture

Source: ARCHITECTURE.md in the runtime repository · All docs

MindOS answers one question continuously: what is true right now, and what evidence proves it? Every layer exists to keep SQLite the single execution authority and to make every mutation auditable and reversible.

CLI surface        autopilot.py (tasks) · ops.py (fleet ops) · verify.py (suite)
Guarantees         leases w/ fencing epochs · audit hash chain · receipt
                   sealing · secret guard · FTS search
SQLite home        state.db (execution authority) · temporal.db (optional
                   fact-graph sidecar)
Migration/inventory   dry-run-first manifests · rollback journal ·
                   orphan quarantine · sealed brain inventory

Core invariants

  1. Single authority — SQLite is the execution authority; Hindsight remains a shared semantic bank and is never copied into SQLite as a second one.
  2. Fail closed — ambiguity/corruption refuses with exact blockers; absent optional sources are recorded honestly without blocking.
  3. Evidence over claims — completions require sealed receipts; audit events are digest-only where values could be sensitive.
  4. Dry-run first — destructive operations plan first, apply only on an explicit flag, journal for rollback, and re-run idempotently.
  5. Source immutability — migration reads never mutate their sources; full-fixture hash comparisons prove it.

The three surfaces

autopilot.py carries execution truth (tasks, leases, receipts, facts, handoffs, dispatch planning, metrics). ops.py carries fleet operations (recovery, escalation, doctor, policies, migration, brain inventory). verify.py is a self-contained end-to-end suite with failure injection, race injection, interrupted re-runs, and rollback-to-zero exercises.
