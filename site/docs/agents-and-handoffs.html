Agents and handoffs

Source: README.md in the runtime repository · All docs

The handoff protocol

handoff transfers a task between agents with an objective and structured fields. The response embeds the full recall bundle — task header, dependencies, live handoff, receipts, and notes — so the receiving agent resumes with evidence rather than a chat summary.

Resume: the recovery half

resume is the one-call, idempotent recovery path for killed sessions: it reconstructs state and hands back the recall bundle without double-executing work.

Lineage

handoff-history walks the full sequence oldest → newest, showing how ownership, objective, and evidence evolved across agents.

Secret guard

note, supersede-note, and handoff scan their content with shape detectors (AWS keys, tokens, credential-shaped values) and block or redact by default. An explicit, itself-audited --allow-secret override exists for fleet sweeps that must locate them.
