MindOS — Autopilot v2

CLI reference

Source: README.md in the runtime repository · All docs

Two entry points: autopilot.py (execution truth) and ops.py (fleet operations). All commands accept the home via MINDOS_HOME / HERMES_AUTOPILOT_HOME.

autopilot.py — tasks

init · create · list · claim · heartbeat · receipt · update · complete · fail
release · renew · leases · transfer · resume · cancel · defer · tag · untag
next --claim · plan · show · search · session-scan
fact-assert · facts · search-facts · metrics · verify-chain · events · dashboard

ops.py — fleet operations

doctor · recover · escalate · policy
brain-inventory · brain-inventory-check
migrate-import · migrate-rollback

verify.py — end-to-end suite

Self-contained: builds disposable fixture homes and exercises every command, including failure injection, race injection, interrupted re-runs, rollback to zero, source immutability, secret-guard refusal/redaction, FTS drift, Hindsight-unavailable degradation, and cross-agent probes.
