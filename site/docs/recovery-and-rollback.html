Recovery and rollback

Source: ARCHITECTURE.md in the runtime repository · All docs

Guarded stale-lease recovery

recover sweeps stale leases with guarded, reported skips so mid-sweep claims are never wiped. leases --all previews exactly what a sweep would take.

Killed sessions

resume gives idempotent killed-session recovery with the full recall bundle — no double execution, no lost evidence.

Migration rollback

python3 ops.py migrate-import … --dry-run   # plan first
python3 ops.py migrate-import …              # journal written
python3 ops.py migrate-rollback …           # target restored to pre-import state

Everything destructive plans first: dry-run manifests, explicit apply flag, rollback journal, idempotent re-runs. Orphans are quarantined with provenance, never dropped.

Integrity

verify-chain recomputes the audit hash chain and reports tampering, with checkpoint-based truncation detection. ops.py doctor adds FTS5 drift detection via fts5vocab.
