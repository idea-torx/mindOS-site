The durable local operating system for Hermes and cooperating AI agents.

MindOS is a shared control plane for execution state, memory, temporal facts, handoffs, receipts, and recovery. It answers one question continuously: what is true right now, and what evidence proves it?

The problem

Agent fleets drift without execution truth.

When several agents work in parallel, memory and intent live in chat transcripts, scratch files, and Git history. None of those answer the operational questions: who holds this task, is the lease still live, what evidence backs “done”, what changed while a session was dead, and how do you roll back a bad import?

01

Claims without evidence

“Tests pass” in a chat message is not proof. Completions in MindOS require hash-sealed receipts stored as 0600 evidence files with sha256 recorded in the audit trail.

02

Stale ownership

Dead sessions leave phantom owners. Live leases with monotonic fencing epochs reject stale processes even when the owner name still matches.

03

Unrecoverable migrations

Import scripts mutate sources and leave no way back. MindOS migration is dry-run-first, byte-immutability-proven, journaled, and one-command reversible.

Product model

A control tower, not another cloud brain.

MindOS combines five systems behind one CLI surface:

autopilot.py

Execution truth

Tasks, claims, live leases with fencing epochs, heartbeats, retry budgets and backoff, dependency edges, impact analysis, dispatch planning, and metrics — all in SQLite.

hindsight binding

Shared semantic memory

Hindsight remains the semantic brain through an explicit, provider-neutral binding. SQLite is the single execution authority — Hindsight is never copied into it as a second one.

temporal.db

Temporal facts

A provenance-linked fact graph of evolving ownership, priorities, validity windows, superseded decisions, and blockers, with BM25 retrieval and temporal hybrid rerank.

ops.py

Recovery and portability

Sealed inventories across nine source kinds, guarded stale-lease recovery, escalation, doctor health checks with FTS5 drift detection, quarantine, and cross-agent handoffs with recall digests.

Architecture

Four layers, one authority.

Every layer exists to keep SQLite the single execution authority and to make every mutation auditable and reversible.

Fail closed

Ambiguity and corruption refuse with exact blockers. Absent optional sources are recorded honestly without blocking the rest.

Tamper-evident audit

A global hash-chained event stream; verify-chain recomputes the chain and reports tampering, with checkpoint-based truncation detection.

Workflow

Claim, fence, prove, complete.

A real task moving through the control plane — every command below is a shipped MindOS command.

mindos — task lifecycle
$ python3 autopilot.py create --project Trove --title "Ship render fix" --priority P1 task created id=tsk_4f2a priority=P1 project=Trove $ python3 autopilot.py claim tsk_4f2a --owner hermes --minutes 30 lease acquired owner=hermes expires_in=30m lease_epoch=1 $ python3 autopilot.py heartbeat tsk_4f2a --owner hermes --epoch 1 --note "Running verification" heartbeat ok status=running window=15m $ python3 autopilot.py receipt tsk_4f2a --kind verification --payload '{"tests":"pass","health":200}' receipt sealed kind=verification file=0600 sha256=9c1f…e7 $ python3 autopilot.py complete tsk_4f2a --owner hermes --epoch 1 --note "tests pass" task completed evidence=sealed receipt required ✓

Completions without a live, epoch-matched lease are rejected. Failures feed retry budgets and dispatch backoff instead of disappearing.

Recovery

Everything destructive plans first.

Dry-run first. Migration inventory and import plan against a disposable target, apply only on an explicit flag, and journal every step for rollback. Re-runs are idempotent.

Sources stay immutable. Migration reads never mutate their sources — full-fixture hash comparisons in the end-to-end suite prove it.

Orphans are quarantined, not dropped. Foreign receipts are quarantined with full provenance instead of breaking foreign-key integrity or losing evidence.

Killed sessions resume. resume gives idempotent killed-session recovery; recover sweeps stale leases with guarded, reported skips so mid-sweep claims are never wiped.

python3 ops.py migrate-rollback …   # one-command recovery
python3 ops.py doctor               # health, incl. FTS drift
python3 autopilot.py verify-chain   # audit integrity
mindos — recovery rail
$ python3 ops.py brain-inventory --out inventory.json manifest sealed 9 source kinds · read-only · redacted $ python3 ops.py brain-inventory-check inventory.json seal verified hash match ✓ $ python3 ops.py migrate-import … --dry-run plan: 214 tasks · 1,880 receipts · 0 conflicts 3 orphan receipts → quarantine (provenance kept) $ python3 ops.py migrate-import … import applied journal=rollback.json ready $ python3 ops.py migrate-rollback … target restored to pre-import state ✓

Honest comparison

MindOS vs files + Git.

Git remains the right tool for code. MindOS is not a Git replacement — it is the operational layer Git was never designed to be, and it complements rather than replaces your repos.

QuestionFiles + GitMindOS
Who is working on this right now?Nothing authoritativeLive leases with fencing epochs, fleet-wide leases view
What proves “done”?Commit messages, at bestHash-sealed receipts (0600 files + sha256) required by policy
What happened while a session was dead?Reconstruct by reading logsIdempotent resume, recall digests, audited event stream
Can a bad import be undone?Depends on the scriptDry-run-first, journaled, one-command rollback to pre-import state
Was the record tampered with?Not detectableverify-chain recomputes the audit hash chain

Security boundary

A registry and evidence layer — nothing more.

MindOS does not deploy, merge, or push code; send external messages or write to external APIs; submit applications; run arbitrary agent commands; or touch Keychain or credential stores. All state lives in a local SQLite home. Every user-supplied text field passes a built-in secret guard that blocks, redacts, or — only under an explicit, itself-audited override — allows credential-shaped values, so fleet sweeps can still locate them.

Live databases, receipts, session archives, Hindsight exports, and agent memory contents are never committed to the repository.

Get started

Clone, init, doctor. That’s the install.

No server, no third-party packages — Python 3.9+ standard library on macOS or Linux.

git clone <repo-url> mindos
cd mindos
export MINDOS_HOME="$HOME/.hermes/mindos"   # any writable path works
python3 autopilot.py init
python3 ops.py doctor                        # health-check the new home
